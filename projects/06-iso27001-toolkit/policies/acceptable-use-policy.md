# Acceptable Use Policy

| Field | Value |
|---|---|
| **Document Owner** | HR Lead / CTO |
| **Version** | 1.0 |
| **Review Cycle** | Annually |
| **ISO 27001 Reference** | Annex A.8 (Asset Management) |

## 1. Purpose
This policy defines the acceptable use of LendStack's information assets, including laptops, mobile devices, software, and customer data. It protects the company and its customers from security risks caused by careless or malicious employee behavior.

## 2. Scope
This policy applies to all employees, contractors, interns, and third parties who access LendStack systems or handle company-issued equipment.

## 3. Device Security
- **Full Disk Encryption:** All employee laptops must have Full Disk Encryption enabled (FileVault for macOS, BitLocker for Windows). This protects data if a device is lost or stolen.
- **Screen Lock:** Devices must be configured to lock automatically after 5 minutes of inactivity.
- **Patching:** Operating systems and software must be updated with the latest security patches within 14 days of release. 
- **Personal Devices (BYOD):** Personal devices are not permitted to store customer data (Restricted data). Mobile access to email and Slack requires device-level PIN or biometric lock.

## 4. Network & Internet Usage
- **Public Wi-Fi:** Connecting to untrusted public Wi-Fi (e.g., coffee shops, airports) without a VPN is strictly prohibited when accessing production systems or customer data.
- **VPN:** The company VPN (or a secure Zero Trust equivalent) must be used for all remote administrative access.
- **Browsing:** Employees must not visit illegal, malicious, or explicitly prohibited websites on company devices. 

## 5. Data Handling & Classification
- **Confidentiality:** Customer data (PII, financial records) is classified as Restricted. It must only be accessed when required for a specific job function.
- **Removable Media:** Unapproved USB drives or external hard drives are strictly prohibited. Use the company-approved secure file sharing tools (e.g., Google Workspace, AWS S3).
- **Data Exfiltration:** Employees must not copy, download, or transfer customer data to personal accounts or devices.

## 6. Email & Phishing
- **Phishing Awareness:** Employees must remain vigilant for phishing attacks. If an email looks suspicious (unexpected attachments, urgent requests for credentials), do not click links.
- **Reporting:** Use the "Report Phishing" button in the email client. If a link was accidentally clicked, report it to the Security Lead immediately. There is no penalty for reporting an honest mistake.

## 7. Software Installation
- Employees must not install unauthorized software (e.g., cracked licenses, peer-to-peer file sharing apps, unapproved browser extensions) on company devices.

## 8. Reporting Violations
Violations of this policy may result in disciplinary action, up to and including termination. If you suspect a violation has occurred, report it to the Security Lead immediately.
